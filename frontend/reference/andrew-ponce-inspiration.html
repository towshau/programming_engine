💡 How the Update Workflow Works
Coaches continue posting in the Slack programming channel exactly as they do now — including the emoji trigger that routes the note to a programmer. Nothing changes there. The improvement is in what coaches are trained to include in that message: client name · exercise · issue type · severity · and the why. That's an onboarding standard, not a system change. When those five things are in the Slack note, this interface reads it, categorises it automatically, assigns it to the program owner, and tracks it until it's actioned. Same workflow — no drop-off.
