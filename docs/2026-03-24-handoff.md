## Bugs fixed today

- **Bug A: Save mismatch/randomized result after Save Program**
  - Symptom: saved program could differ from the visible editor state; partner view mismatch.
  - Fix: save now writes the fully computed sessions into `programming_generated.payload` and resets upload flag when needed.

- **Bug B: Wrong exercise being edited when labels are blank**
  - Symptom: edits in Additional section reverted, changed the wrong row, or only top row behaved correctly.
  - Root cause: multiple rows had both `exercise_id: null` and `series_label: ""`, so matching/cancellation logic hit the first row.
  - Fix: `exercise_index` introduced as a deterministic fallback matcher through edit creation, apply, and cancellation chain logic.
