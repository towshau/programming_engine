# Retool prompt: PDF Export

Paste this into Retool's AI app builder.

---

## Prompt

Add a PDF export feature to the Program Viewer page. When a coach clicks "Export PDF", generate a clean, printable PDF of the selected program.

### Trigger

Button on the Program Viewer detail panel: "Export PDF"

### What to include in the PDF

1. **Header:**
   - Member name (from member_id join)
   - Scheme name, rep range, phase number
   - Duration: X weeks
   - Sessions per week
   - Generated date (created_at)
   - Changes summary (if present)

2. **For each day/session:**
   - Day number as section header (e.g. "Day 1")
   - Table with columns: Series (A1, A2, B1...), Exercise Name, Sets × Reps
   - Rows grouped visually by series letter (A-series together, B-series together, etc.)

3. **Footer:**
   - "Generated by Lockeroom Programming Engine"
   - Date exported

### Implementation approach

Option A — Retool's built-in PDF generation:
- Use a Retool "Generate PDF" action with an HTML template
- Template iterates over payload.sessions and renders the table

Option B — External (if Retool PDF is limited):
- Call a Supabase Edge Function that takes the program payload and returns a PDF
- Store in Supabase Storage, return a signed URL
- Open the URL in a new tab

### HTML template (for Option A)

```html
<div style="font-family: Arial, sans-serif; padding: 20px;">
  <h1>{{ member_name }} — Program</h1>
  <p><strong>Scheme:</strong> {{ scheme_name }} | <strong>Rep Range:</strong> {{ rep_range }} | <strong>Phase:</strong> {{ phase_number }} | <strong>Duration:</strong> {{ duration_weeks }} weeks</p>
  <p><strong>Sessions/week:</strong> {{ sessions_per_week }} | <strong>Generated:</strong> {{ created_at }}</p>
  {{#if changes_summary}}<p style="background: #f0f0f0; padding: 8px; border-radius: 4px;">{{ changes_summary }}</p>{{/if}}

  {{#each sessions}}
  <h2 style="margin-top: 24px; border-bottom: 2px solid #333;">Day {{ this.day }}</h2>
  <table style="width: 100%; border-collapse: collapse; margin-top: 8px;">
    <thead>
      <tr style="background: #f5f5f5;">
        <th style="text-align: left; padding: 6px; width: 60px;">Series</th>
        <th style="text-align: left; padding: 6px;">Exercise</th>
        <th style="text-align: center; padding: 6px; width: 100px;">Sets × Reps</th>
      </tr>
    </thead>
    <tbody>
      {{#each this.exercises}}
      <tr style="border-bottom: 1px solid #ddd;">
        <td style="padding: 6px; font-weight: bold;">{{ this.series_label }}</td>
        <td style="padding: 6px;">{{ this.exercise_name }}</td>
        <td style="text-align: center; padding: 6px;">{{ this.sets.length }} × {{ this.sets.[0].reps }}</td>
      </tr>
      {{/each}}
    </tbody>
  </table>
  {{/each}}

  <p style="margin-top: 32px; color: #999; font-size: 12px;">Generated by Lockeroom Programming Engine</p>
</div>
```
